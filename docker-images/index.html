Releases are read from ROCm/ROCm and ROCm/TheRock; anything older than a year is left off unless CI still builds it. Which version a CI track tests is read from what its Dockerfile stage installs, not from the track's name: rocm10 builds the *-rocm1000 stages, and those install whatever ROCM1000_SDK_VERSION says. A release is superseded when it is not tested but CI tests a newer release on its line (7.2.3 by 7.2.4), or any newer ROCm when CI tests nothing on its line (7.14 by 10.0).
